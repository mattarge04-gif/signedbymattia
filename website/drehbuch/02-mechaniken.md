# Drehbuch 02: Mechaniken (was beim Scrollen und Überfahren passiert)

Stand: 29.09.2026 · Status: **Befund [F]** · Methode: Shopify Editions Winter '26 in Scroll-Schritten
von 160 px gefilmt (1280×800, 6 Kapitel, 134 Bilder) plus Maus-Test links/rechts. Filmstreifen lokal:
`_rohdaten/teardown/www.shopify.com/film/bogen-*.png`. Wir übernehmen Mechaniken, keine Inhalte.

## Wichtigste Erkenntnisse [F]

1. **Das Wow kommt vom Scroll, nicht von der Maus.** Die Szenen reagieren auf die Maus kaum
   (Maus links/rechts: praktisch gleiches Bild). Jedes Kapitel spielt beim Scrollen eine kleine
   **Choreografie in 3–4 Stationen** ab; bei jeder Station wechselt der Text.
2. **Die Maus weckt die Karten.** Über einer Feature-Karte klappt die Beispiel-Eingabe zum
   Ergebnis auf (Tabelle, Ablauf). Das ist der „Was macht es, wenn ich drüber fahre"-Moment.
3. **Jede Szene lebt:** Irgendwo läuft immer etwas (Video auf der Plakatwand, Code auf dem
   Monitor, Glühen im Globus), auch wenn man stillsteht.
4. **Rhythmus:** Szene (Staunen) → Papier (Lesen) → Szene (Staunen). Nie zwei Lese-Blöcke hintereinander.
